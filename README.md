## Projetos

### [CMEasy — Ferramenta CLI de Automação para Administração de Sistemas e Cibersegurança](https://cmeasy.cleisonmq.com)
Desenvolvi uma ferramenta CLI interativa em Python 3 para automação de tarefas de administração de sistemas, gestão de redes e cibersegurança, com suporte multi-plataforma (Linux Debian/Red Hat e Windows).

Integra módulos de hardening, controlo de acessos, auditoria de acessos ao sistema, auditoria de serviços de rede, gestão de utilizadores/grupos, firewall (UFW/Firewalld), SSH, Fail2Ban, Wazuh, Squid Proxy, WireGuard e Nextcloud.

Reduziu em 70% o tempo de execução manual de tarefas repetitivas de administração e segurança.
